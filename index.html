Profile

I build reproducible pipelines that turn ocean observations and model output into high-quality, open data products. My work spans quality control of buoy, glider, and mooring records; satellite altimetry (SWOT) data assimilation; and climate-model analysis, with recent applications to AI-enabled coastal flooding intelligence.

Current Work (WHOI)

  • Develop reusable algorithms and documentation workflows for geospatial/ocean data across multiple field programs.
  • QC and process buoy, wave-glider, and mooring observations into flux and long-term temperature datasets.
  • Standardize methods to deliver consistent, well-documented, open-access data products.
  • Build Python tools for laboratory and field sensor analysis (e.g., submersible humidity sensor).
  • Created an AI-powered flood monitoring system integrating real-time news and NOAA alerts to support SWOT coastal water-level and flood-mapping work.

Selected Results

  • Deep Ocean Temperature from the Stratus Ocean Reference Station (85°W, 20°S), 2012–2025 — data descriptor in preparation, to be submitted to Nature Scientific Data (Gao, Plueddemann, Weller, Bigorre).
  • Python-based data assimilation methods improving SWOT sea-surface height accuracy; joint optimization of model fields and correlated errors (UC San Diego postdoc).
  • Southern Ocean studies: mesoscale mixed-layer heat budgets, air–sea coupling with regional coupled models, and drivers of mixed-layer depth variability.
